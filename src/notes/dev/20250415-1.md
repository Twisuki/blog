# C语言其中考试模拟题知识点摘录

<!-- more -->

C语言的语句也可以有返回值, 例如:

```C
int a = 1;
if (a = 0) {
	// 不会执行
}

if (a = -1) {
	// 会执行
}
```

C语言的赋值语句返回值是所赋的值, 上述`a = 0`返回`0`, 而`if`中, `0`被处理成`false`, 则不执行.

而下面`a = -1`返回`-1`, 被`if`处理成`true`, 执行.

同理, `printf()`语句也有返回值:

```C
printf("%d", printf("abc\n"));
```

该语句运行结果为:

```
abc
4  
```

可见, `printf()`语句返回值为打印字符的个数.

此外, 还有`scanf()`:

```C
int a, b;
int s = scanf("%d %d", &a, &b);
printf("%d", s);
```

当我们输入`1 2`时, `printf()`将打印`2`; 当我们输入`1 a`时, `printf()`将打印`1`. `scanf()`的返回值是录入成功的数据的组数.
